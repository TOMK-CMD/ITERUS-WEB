Iterus builds custom web applications, AI integrations and connections to Czech systems (ARES,
data boxes, NEN) on a project basis. We use Next.js, TypeScript and PostgreSQL/Supabase; AI is
integrated through the Claude and OpenAI APIs. Five services have their own detail page below; the
rest we deliver as part of a project.

## Frequently asked questions

<Faq>
  <FaqItem question="Do you also build mobile apps?">
    Yes, in React Native / Expo — a native app for iOS and Android, not a website wrapped in an
    app. The mobile layer calls the web API we build ourselves; that is exactly how
    <PageLink href="/references/legacy-you">Legacy You</PageLink> is built, with the web and the
    mobile app sharing one backend.
  </FaqItem>
  <FaqItem question="Will you take over a project started by another vendor?">
    Yes. We review the code and tests first to see what state it is in — without that we give no
    estimate to finish. The first phase ends with a written finding: what holds, what needs
    rewriting and why; only then do you decide whether to continue with us.
  </FaqItem>
  <FaqItem question="What do you not do?">
    Banking core systems, penetration testing and security audits, medical devices (MDR),
    embedded-device development and large enterprise migrations without a dedicated team — the
    list above reflects where we stand today. We would rather limit scope up front than promise
    work whose quality we could not stand behind.
  </FaqItem>
</Faq>
