We build web applications in Next.js and TypeScript, with a PostgreSQL or Supabase database,
automated tests and deployment in the EU (Frankfurt). A validation pilot — authentication,
database, one or two integrations, tests, deployment — ships in 3-6 weeks from 90,000 CZK; a
production version with roles, payments and more integrations runs 250,000-700,000 CZK.

## What's included?

The same stack we use on our own products: Next.js, TypeScript, PostgreSQL or Supabase, automated
tests and CI, deployment on Vercel.

## Frequently asked questions

<Faq>
  <FaqItem question="How long until the first usable version?">
    A validation pilot ships in 3-6 weeks — a working version in production, not a prototype
    without a database or tests.
  </FaqItem>
  <FaqItem question="Where does the app run, and what does it cost to operate?">
    We deploy on Vercel in the EU (Frankfurt) with a PostgreSQL or Supabase database in the same
    region; we calculate the exact running cost from expected load during the consultation.
  </FaqItem>
  <FaqItem question="Can you connect to an existing database?">
    Yes — we first audit the schema and design a connection or migration without data loss.
  </FaqItem>
  <FaqItem question="What if I want to change the scope?">
    We work in short iterations, so a scope change is folded into the next one — a bigger change
    affects the estimate, not the work already done.
  </FaqItem>
</Faq>
