We build web applications in Next.js and TypeScript, with a PostgreSQL or Supabase database,
automated tests and deployment in the EU (Frankfurt). A validation pilot — authentication,
database, one or two integrations, tests, deployment — ships in 3–6 weeks from 90,000 CZK; a
production version with roles, payments and more integrations runs 250,000–700,000 CZK.

## What's included?

The same stack we use on our own products: Next.js, TypeScript, PostgreSQL or Supabase, automated
tests and CI, deployment on Vercel. On payment you own 100% of the source code and documentation,
and another team can take the project over without training on a proprietary tool.

## Where does this run in production?

In all three products with a case study. <PageLink href="/references/legacy-you">Legacy
You</PageLink> is a web app and a native mobile app for iOS and Android on one Supabase backend —
with accessibility as a CI requirement, not a promise.
<PageLink href="/references/innea">Innea</PageLink> and
<PageLink href="/references/innea-pro">Innea Pro</PageLink> share one codebase with each user's
data isolated in the database itself (Row Level Security) and thousands of automated tests, whose
counts are in the case study. You get the same stack, the same tests, the same deployment.

## Frequently asked questions

<Faq>
  <FaqItem question="How long until the first usable version?">
    A validation pilot in 3–6 weeks: a working version in production with authentication, a
    database, one or two integrations, tests and deployment — not a prototype without a database
    or tests. If the brief isn't clear yet, a paid discovery comes first, and its fee is deducted
    from the project.
  </FaqItem>
  <FaqItem question="Where does the app run, and what does it cost to operate?">
    On Vercel in the EU (Frankfurt) with a PostgreSQL or Supabase database in the same region —
    the same as our own products. You pay the running costs directly to the providers, not to us;
    we calculate them from the expected load during the consultation so the bill holds no
    surprises.
  </FaqItem>
  <FaqItem question="Can you connect to an existing database?">
    Yes. We first audit the schema and design a connection or migration without data loss — every
    irreversible database change is approved by a human, a rule we keep on our own products too.
  </FaqItem>
  <FaqItem question="What if I want to change the scope?">
    A smaller change is folded into the next step at no change in price — we work in short
    iterations. A bigger change of scope affects only the estimate for the remaining work, not
    what is done and paid for; you hear about it immediately, not on the invoice.
  </FaqItem>
</Faq>
