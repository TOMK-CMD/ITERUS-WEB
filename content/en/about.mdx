Iterus is the software brand of SUN Professionals s.r.o., a company trading since 2005. Software
under the Iterus brand has been built since 2025 — three of the products built since then have
their own <PageLink href="/references">case studies</PageLink> with numbers from the repositories.

## What have we built?

We build production web and AI applications — Next.js, TypeScript, PostgreSQL/Supabase, Claude and
OpenAI API integrations. Delivery is accelerated with Claude Code and Codex; quality is secured by
human oversight, automated tests and independent code review. What that looks like in practice is
shown by <PageLink href="/references/innea">Innea</PageLink> (AI support with a crisis layer),
<PageLink href="/references/innea-pro">Innea Pro</PageLink> (Czech billing and health insurers)
and <PageLink href="/references/legacy-you">Legacy You</PageLink> (a native mobile app for
seniors).

## Who is behind it?

Iterus is run by Tomáš Kučera. Technology has always interested me, and I wanted to build my own
applications for years — running a business never left the time for it. Language models and tools
like Claude Code and Codex changed that: the path from intent to a running application got short
enough to be worth taking. I started with tools for my own company, where I knew the problem best
and carried the cost of any mistake myself. They worked, so I kept going — and Iterus came out of
it.
